                Баг-репорты на платформе модераций объявлений

**Заголовок:**
После ввода валидных данных в поле "Диапазон цен" появление карточек с ценами мимо диапазона

**Предусловие:**
1. Включить VPN
2. Открыть сайт https://cerulean-praline-8e5aa6.netlify.app/

**Шаги:**
1. В поле "От" ввести 100
2. В поле "До" ввести 1000

**ФР:**
Есть карточки с ценами выходящие за диапазон

**ОР:**
Карточки объявлений отфильтровались в пределах ценового диапазона

**Окружение:**
Google Chrome Версия: 146.0.7680.178 (официальная сборка) (64 бит)
Windows 11 версии 25H2

**Приоритет:** Р2
